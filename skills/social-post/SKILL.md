# Social post

1. Read the source: the message, a file via `search_files`, or a recording via `transcribe_audio`.
2. Write three versions: LinkedIn (up to 1,300 characters, professional), X (under 280 characters), Instagram (caption plus 5 hashtags).
3. Keep claims to what the source says.
4. Offer to keep the drafts with `save_document` (Markdown).
