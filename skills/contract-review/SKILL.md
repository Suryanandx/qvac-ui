# Contract review

1. Read the document with `search_files` (or `read_image_text` / `look_at_image` for scans).
2. List: parties, effective date, term and renewal (auto-renew? notice period?), payment terms, termination rights, liability caps, governing law, confidentiality.
3. Flag clauses that are one-sided or unusual, quoting the clause text.
4. State clearly that this is a summary, not legal advice.
