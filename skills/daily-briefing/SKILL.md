# Daily briefing

1. Use `tool_search` to find what is connected: calendar (Google/Outlook), email, weather, Hacker News.
2. Gather: today's meetings, emails that need a reply, the local forecast, three top stories.
3. Present a short briefing with sections; skip any section whose connector is not set up and say how to connect it.
4. Offer to read it aloud with `speak`.
