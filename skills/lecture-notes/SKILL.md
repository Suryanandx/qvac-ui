# Lecture notes

1. Transcribe with `transcribe_audio` (or `meeting_notes` for long recordings).
2. Write: a one-paragraph overview, key concepts as bullets with plain-language definitions, and worked examples if any were given.
3. Add a five-question quiz with answers at the end.
4. Offer to read the summary aloud with `speak`.
