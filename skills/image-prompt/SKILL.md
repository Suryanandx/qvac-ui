# Image prompt

1. Expand the idea into: subject, setting, style, lighting, composition, colour palette (one sentence each, comma-joined).
2. Call `generate_image` with that prompt. If the image model is not installed, explain how to download it in Settings → Models.
3. Offer one or two variations.
